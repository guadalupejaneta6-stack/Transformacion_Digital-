# Transformacion_Digital

Este proyecto se desarrolló como parte de la asignatura Cultura y Sociedad Digital de la carrera de Ciencia de Datos.
El propósito del repositorio es explicar la importancia de la transformación digital en la ciencia de datos y aplicar buenas prácticas de programación utilizando Git y GitHub. La transformación digital brinda una oportunidad para mejorar procesos, optimizar el procesamiento de la información y facilitar la toma de decisiones utilizando tecnologías digitales. Hoy en día, muchas organizaciones utilizan herramientas digitales para analizar datos y ofrecer mejores servicios. El repositorio tiene un ejemplo simple de Python para promediar una lista de números usando funciones y documentación con cadenas de documentos.
